# AutoComp Corp

Corporate-compliance operations concept for source monitoring, evidence organization, draft preparation and permissioned human review.

Public website: https://autocompcorp.josephjilovec.com/

## Public experience

- `/` — product overview, illustrative operational displays and control boundaries.
- `/assessment` — readiness-review interface.

Examples explain how obligations, drafts, approvals and receipts could be connected. They do not establish live registry coverage, customer compliance status or completed filings. Consequential signatures, payments, filings and governance actions remain with authorized officers and qualified professionals. Missing evidence is not proof of compliance.

## Development

Next.js App Router and TypeScript.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Preserve the existing Vercel project and root deployment settings. Consult `.env.example` for optional server-side routing variables. Never commit live secrets or expose them through browser code. Production submissions require a separately configured and tested secure service; the public demonstration does not provide that authorization.

Detailed internal operating models, implementation planning and commercial assumptions are maintained in restricted records. Existing application source remains in this repository; this documentation change does not move or activate backend services. Earlier documentation may remain in public Git history.
